## **Critical Problem Solved**

- The site was a pure client-rendered SPA: `index.html` shipped an empty `#root`, so anything that fetches HTML without executing JavaScript saw zero body text and zero links on every route.

- `404.html` used a `sessionStorage` SPA redirect that soft-404'd unknown URLs onto the homepage — bad for SEO and for typo'd deep links.
- During close-out of PR #31, a **legacy GitHub Pages branch deploy raced the Actions workflow** and briefly served the unbuilt SPA shell (deep links 404'd for ~37s). Fix is a Settings change (Pages source → GitHub Actions), not code.

## **Technical Implementation Details**

### **Prerender Architecture**
```text
siteRoutes → sitemap.xml (drift-tested) → script/prerender.js
  → vite preview(dist) + Playwright Chromium
  → dist/.../index.html with data-prerendered
  → assert:prerendered (CI / build:static)
```
- `createRoot` stays; React discards the snapshot and re-renders. `hydrateRoot` was rejected (post-effects mismatch).
- Fast loop remains `npm run build`; Chromium only for `build:static` / full verify.

### **Metadata Ownership**
- Managed head tags use `data-managed-meta`: each navigation removes prior managed nodes, then reinserts — prevents duplicate accumulation across client navigations and prerender re-runs.
- `absoluteUrl()` centralizes origin+path construction for canonicals, OG, and JSON-LD.

### **Ops Gap (Settings, Not Code)**
- Pages must use **Source: GitHub Actions**. Leaving “Deploy from a branch” enables a race where the legacy workflow can briefly publish the unbuilt SPA shell.
